📖 사용 방법

1. 의존성 설치
pip install -r requirements.txt

2. 워크플로우 실행
# 배치 파일
run_workflow.bat

# 또는 직접
python workflow/main.py

3. 대시보드 실행
# 배치 파일
run_dashboard.bat

# 또는 직접
streamlit run workflow_dashboard/app.py

1. 기존 대시보드 (데이터 조회용)
위치: dashboard/app.py
기능:
수집된 가격/뉴스 데이터 조회
ML 분석 결과 (이상치, 변동, 예측) 시각화
카테고리별 상품 목록

실행:
streamlit run dashboard/app.py

# 또는
python -m streamlit run dashboard/app.py

2. 새 대시보드 (워크플로우 제어용)
위치: workflow_dashboard/app.py
기능:
LangGraph 워크플로우 실행/모니터링
자동 리포트 생성 및 조회
체크포인트 관리

실행:
streamlit run workflow_dashboard/app.py

# 또는
run_dashboard.bat
